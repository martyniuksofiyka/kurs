# План тестування та протокол результатів

**Робота:** PhotoStudio Manager **Версія:** 1.0.0
**Середовище автотестів:** macOS 14, Apple clang 15, Qt 6.9.3, CMake 4.5.0
**БД та відновлення даних:** кожен автотест створює окрему тимчасову БД (QTemporaryDir) за схемою
`db/schema.sql`; робоча БД не змінюється. Для ручних тестів - `PhotoStudio --db test.db --reset-demo`.

Запуск автотестів: `ctest --test-dir build --output-on-failure` або `build/tst_core`.
